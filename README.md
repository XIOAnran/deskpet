# 🦦 小海桌宠 v2.0

一个基于 PyQt5 的 Windows 透明桌面宠物程序。去除图片背景、窗口透明无边框、始终置顶、可拖拽、互动动画、对话气泡。

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 🪟 透明窗口 | 完全透明无边框，浮在桌面上 |
| 📌 始终置顶 | 右键菜单可开关 |
| 🖱️ 左键拖拽 | 移动位置，带走路动画 |
| 👆 左键点击 | 轮流触发：跳跃→压扁回弹→左右抖动→摸摸头→开心→打招呼 |
| 👆👆 左键双击 | 弹出聊天对话 |
| 🎯 右键菜单 | 互动/动作/设置/置顶/退出 |
| 🌀 鼠标滚轮 | 放大/缩小宠物 |
| 💬 对话气泡 | 40+ 句有趣中文，自动显示 |
| 💤 睡觉模式 | 呼吸动画 + Zzz 气泡 |
| 🚶 走路模式 | 随机漫步 |
| 🖱️ 跟随鼠标 | 宠物跟着鼠标跑 |
| 🎵 跳舞模式 | 随音乐摇摆 |
| ⌨️ 快捷键 | ESC=退出, W=走路, S=睡觉, F=跟随, T=置顶 |

## 🚀 快速构建 EXE

### 方式一：GitHub Actions（推荐，零安装）

1. 将此文件夹上传到 GitHub 仓库
2. 进入 **Actions** 标签页，选择 **构建小海桌宠** 工作流
3. 点击 **Run workflow** → **Run workflow**
4. 等待几分钟，在运行结果中下载 `小海桌宠.zip`
5. 解压得到 `小海桌宠.exe`，双击运行

### 方式二：本地双击构建（Windows 电脑）

**前提条件：** 安装 [Python 3.8+](https://www.python.org/downloads/)（安装时勾选 Add Python to PATH）

**步骤：**
1. 进入 `小海桌宠` 文件夹
2. **双击 `build.bat`**（或右键以管理员运行）
3. 等待约 1-2 分钟，自动完成所有操作
4. 在 `dist/小海桌宠.exe` 找到程序

### 方式三：PowerShell 构建

在 `小海桌宠` 文件夹中，按住 Shift 右键 → 打开 PowerShell 窗口，运行：
```
.\build.ps1
```

## 🖼️ 更换角色图片

1. 将你的图片命名为 `character.jpg`（或 `character.png`）
2. 替换程序目录下的同名文件
3. 重新运行 `build.bat` 构建

## ⚙️ 自定义设置

编辑 `deskpet.py` 中的以下内容：

- `DEFAULT_CHAT_MESSAGES`：修改对话内容
- `INTERACTION_SPEECH`：修改互动对话
- 默认大小、速度在 `SettingsDialog` 中调整

## 🐛 常见问题

**Q: 构建时报错 "不是内部或外部命令"**
A: 确保 Python 已安装并添加到 PATH，重新打开命令行再试。

**Q: 程序启动后图片不显示**
A: 确保 `character.jpg` 或去背景后的 `character_nobg.png` 在程序同目录下。

**Q: 如何完全卸载？**
A: 删除整个文件夹即可，不写注册表，不留残余文件。

**Q: 背景去除不干净？**
A: 编辑 `remove_bg.py` 中的 `threshold` 参数（默认50），调低去除更严格，调高去除更宽松。
